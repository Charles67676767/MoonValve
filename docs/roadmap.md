# 路线图

## 当前开发版本

- [x] 有序、保留重复键的 KV1 文本模型
- [x] 解析、查询、规范化写出与结构化错误
- [x] 资源限制和核心路径测试
- [x] Steam 应用清单及新旧库目录模型
- [x] 文件 CLI、inventory、可运行示例与持续集成配置
- [x] 重复键感知的编辑与 JSON 双向转换
- [x] 显式平台条件与有界 include/base 解析
- [x] 标准二进制 KV1 编解码
- [x] 保留注释和原始排版的局部编辑
- [x] Steam 筛选排序、容量汇总、重复与缺失检查及 CSV
- [x] 无需 Node 的原生命令行
- [x] 独立二进制参考向量、双向差分、生成式测试与规模基准
- [ ] 首个 Mooncakes 发布版本

## 后续评估

- 收集可公开再分发的实际配置样例，并记录不同 Valve 工具的语义差异。
- 更丰富的格式保留插入样式、批量编辑事务与稳定 API 版本管理。
- appinfo 容器、外部字符串表及其他变体需单独设计，不与标准二进制 KV1 混用。

KV2/KV3 是不同的格式支持工作，新增前会单独定义兼容性范围。
