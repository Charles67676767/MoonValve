## 后续评估

- 继续增加可公开再分发的配置样例，并记录不同 Valve 工具的语义差异；已纳入 Proton 实际清单与模板。
- 在保留旧公开声明的 0.6.x 兼容约定下继续评估后续 API 演进、复杂布局和注释关联规则。
- Steam 缓存的新增版本与其他二进制变体按独立格式扩展，不与标准 KV1 混用。

KV2 与二进制 KV3 仍为独立的后续格式支持工作；当前文本 KV3 范围见 [进阶功能](advanced.md)。
