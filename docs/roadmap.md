# 路线图

## 当前开发版本

- [x] 有序、保留重复键的 KV1 文本模型
- [x] 解析、查询、规范化写出与结构化错误
- [x] 资源限制和核心路径测试
- [x] Steam 应用清单及新旧库目录模型
- [x] 文件 CLI、inventory、可运行示例与持续集成配置
- [ ] 扩充独立兼容性夹具与跨实现差异测试
- [ ] 首个 Mooncakes 发布版本

## 后续评估

- 调用方提供文件解析器的 include/base 语义；明确路径与循环依赖边界。
- 显式平台条件求值，提供条件保留或拒绝的选择。
- 保留注释与原始排版的文档编辑 API。
- 二进制 KV1 编解码。
- 更多实际配置样例及规模基准。

KV2/KV3 是不同的格式支持工作，新增前会单独定义兼容性范围。
