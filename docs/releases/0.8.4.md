# MoonValve 0.8.4

本次聚焦既有能力的边界、失败恢复和可复现使用流程，无新增文件格式。

- 统一资源能力目录，生成 CLI capabilities、工作台说明及支持矩阵；区分结构解析、文件完整性、参考互操作和目标程序运行证据。
- 资源面板清除失败输入的旧模型；串行处理并锁定操作期间的输入；DMX修改后要求重新解析；翻译问题阻止导出。
- Worker超时终止与恢复；真实Chromium文件输入、下载和错误恢复回归。
- 三条可运行流程：配置预览/备份/恢复、静态资源闭包/提取核对、PO更新/编码/占位符拒绝。
- 固定九份上游实际资源的来源、长度和SHA256，并提供显式下载和独立参考验证；原始文件不再分发。
- 修复保存失败后可能残留不完整自建备份的问题；原生宿主按失败阶段给出恢复建议；POSIX进程写限额测试验证临时输出和备份写入失败。
- 变异测试隔离进程、运行预算和失败重放；增加CRC失败回滚、已有目标保护和VPK偏移上限检查。
- 安装、错误恢复、当前验证与历史验证文档分开组织。

工具链为moonc0.10.18+6c83a7f62。根包公开接口保持0.8.x兼容约定。

Windows x64 / Linux x64 ZIP由同一提交的成功CI构建。下载后核对对应 `.sha256`；不要把源码ZIP当作可执行发行包。原生CLI无需MoonBit或Node，本地工作台与任务辅助脚本需Node22+。其他系统与架构没有验证。

VPK仍不验证v2签名，偏移上限2147483647；Source2输出仅限独立DATA容器；静态依赖不保证游戏加载。合成任务中的VTF仅为字节复制样本。没有自动游戏运行验证。
