# 多文件工程与字段来源

工作台的“多文件工程”支持载入本地目录，保留相对目录结构，选择入口和显式条件符号，然后分析生效的 include/base 引用与展开后的字段来源。目录最多 64 个 `.vdf/.acf/.res/.txt` 文件，合计 16 MiB；核心解析累计预算仍单独执行，不会因浏览器允许载入而放宽。

点击工程文件可切换到配置编辑器。切换前，当前文本保存在内存中的工程副本内；有改动的文件在列表中标记。点击引用边可打开指令或目标，点击展开字段则跳回原文件中键的准确位置。来源感知重复项，支持条件过滤、本地覆盖、默认子字段继承和 include 追加。

来源分析依赖当时的全部文件、入口、符号和字面模式；任何一项改变后，应重新分析。旧位置导航会拒绝使用过期结果。行列和偏移按原文 Unicode 标量计算，支持 BOM、中文、非 BMP 字符及 CR/LF/CRLF。

“导出工程快照”保存当前各文件文本及入口到 `moonvalve-project.json`；“恢复快照”可在之后恢复工作。快照是文档副本，不会写回原目录。草稿只在当前页面内存中保存，关闭或刷新前应下载文件或导出快照。浏览器不扫描未选择的目录。

命令行可复现相同的来源分析：

```sh
moonvalve project main.vdf --root fixtures/project --condition WIN32
```

输出含 `tree`、`origins`、`references`。库调用使用 `load_project`；它与 `load_resolved` 共享解析、合并与资源限制。解析器记录键位置，合并时同步保留来源，避免通过最终字符串反向猜测位置。对象本身可来自本地文件，而其中部分子字段来自默认文件；来源按每个字段分别记录。
