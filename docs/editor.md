# 本地可视化工作台

```sh
node scripts/build-editor.cjs
node scripts/serve-editor.cjs
```

打开 `http://127.0.0.1:8765`。本地服务器只绑定本机地址，提供静态文件；文件内容由浏览器 Worker 中的 MoonBit 核心处理，没有上传接口、分析统计或远程资源。首次构建需要已安装的 MoonBit 工具链；界面使用 JavaScript 后端编译的 MoonBit 模块。

- 打开或拖入文本/标准二进制 KV1，浏览树形结构与同名项出现次数。
- 文本模式保留原文注释、平台条件与引用；手动编辑后自动解析，错误显示行列号并可点击定位。
- 选择条目后可预览替换、重命名、删除或插入；确认后仅改变编辑区，可撤销最近 20 次应用。
- 二进制模式显示类型保留 JSON，可在树形视图中选中条目并修改，导出前由核心库校验类型与数值范围。
- 条件预览使用显式符号集合；文件引用只读取用户选择的本地目录。展开结果通过预览后可应用为独立配置。
- “下载结果”生成新副本；“导出 JSON”保留完整有序模型。浏览器不会直接覆写原始文件。

单文件最大 16 MiB；文本解析默认仍为 8,388,608 个 Unicode 标量。引用目录最多 64 个受支持文本文件、合计 16 MiB；目录的顶层名称被去掉，入口使用其内的相对路径。树形面板最多显示 2500 项，完整数据仍在编辑区与导出中保留。输入按 UTF-8 解码；二进制宽字符串由核心库按 UTF-16LE 解释。

界面带重复键、平台条件/引用和二进制快捷方式三个合成示例。自动化核心检查：`node scripts/test-editor.cjs`。
